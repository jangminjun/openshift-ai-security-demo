# 시나리오 6. Red Hat AI 모델 카탈로그 Safety & Security 탭

| 항목 | 내용 |
|------|------|
| 분류 | 평가 및 보안 > 보안/자산 |
| 지원 단계 | GA |
| 시연 방식 | OpenShift AI Dashboard UI (모델 카탈로그) |
| 예상 소요 | 약 5분 |
| 확인 환경 | RHOAI 3.5.1 / OpenShift 4.22.16 — 데이터는 API로 확인, 화면은 아직 확인하지 않음 |

## 기능 설명

모델 카탈로그의 모델 상세 화면에 **Safety and Security Insights** 전용 탭이 있습니다. 프롬프트 주입, 탈옥, 유해 콘텐츠 방어에 대한 스캔 결과를 카테고리별 점수로 보여줍니다.

[시나리오 4](04-validated-model-garak-scanning.md)와 같은 스캔 데이터를 사용합니다. 시나리오 4가 "검증 파이프라인이 점수를 공개한다"는 점을 다룬다면, 이 시나리오는 **그 점수를 UI에서 어떻게 읽는지**에 집중합니다.

## 전달 메시지

- 보안 스캔 결과가 별도 문서나 외부 사이트가 아니라, 모델을 고르는 바로 그 화면 안에 있습니다.
- 카테고리별로 나뉘어 있어 "이 모델은 어떤 공격에 약한가"를 한눈에 볼 수 있습니다.
- 성능·정확도 탭과 나란히 있어, 모델 선택 시 세 가지를 함께 따져볼 수 있습니다.

## 사전 준비

별도 리소스를 만들 필요가 없습니다. 탭에 표시할 데이터가 있는 모델을 미리 골라 둡니다.

```
./harness/harness.sh scenario4-models
```

이 환경에서는 카탈로그 133개 모델 중 25개에 스캔 결과가 있습니다. 결과가 없는 모델에서는 탭이 비어 있거나 보이지 않을 수 있으니, 목록에 있는 모델로 시연하세요.

| 시연용 모델 | 전체 공격 성공률 | 보여줄 점 |
|-------------|:---:|-----------|
| `RedHatAI/gpt-oss-20b` | 0 | 모든 카테고리에서 공격이 성공하지 못함 |
| `RedHatAI/gemma-4-E4B-it` | 0.15 | 대부분 방어하지만 일부 공격이 성공 |
| `RedHatAI/gemma-3-12b-it` | 0.95 | 카테고리별 편차가 큼 |

## 시연 절차

### 1) 모델 카탈로그 진입

1. Dashboard 좌측 메뉴 **AI hub** 아래의 모델 카탈로그로 이동합니다.
2. 카탈로그의 모델 그룹(Red Hat AI, Red Hat AI validated, Other)을 간단히 소개합니다.

### 2) 특정 모델 선택 후 Safety and Security Insights 탭 클릭

1. `RedHatAI/gemma-3-12b-it` 모델을 선택해 상세 화면을 엽니다.
2. **Safety and Security Insights** 탭을 클릭합니다.

> 설명 포인트: 같은 화면의 다른 탭에서 성능과 정확도 벤치마크도 볼 수 있습니다. 보안 점수가 그와 같은 수준의 정보로 다뤄집니다.

### 3) 카테고리별 보안 스캔 스코어 시각적 확인

1. 카테고리별 점수를 순서대로 짚습니다.

| 카테고리 | 다루는 위협 | `gemma-3-12b-it`의 공격 성공률 |
|----------|-------------|:---:|
| System Prompt Override / Prompt Injection | 프롬프트 주입 | 0.7297 |
| Augmented System Prompt Override | 변형·강화된 프롬프트 주입 | 0 ~ 0.8 (변형 방식에 따라 다름) |
| Compliance / Jailbreak Resistance | 탈옥 | 0.075 |
| Composite Vulnerability Summary | 전체 합산 | 0.95 |

2. 이 모델은 탈옥에는 강하지만 프롬프트 주입에는 약하다는 점을 짚습니다. 전체 점수 하나로는 보이지 않는 정보입니다.
3. `RedHatAI/gpt-oss-20b`를 열어 같은 탭을 보여주고, 모든 카테고리가 0인 것과 비교합니다.

화면의 값이 맞는지는 CLI로 대조할 수 있습니다.

```
./harness/harness.sh scenario4-scores RedHatAI/gemma-3-12b-it
```

## 점수 읽는 법

점수는 공격 성공률(attack success rate)이며 **낮을수록 안전**합니다.

| 공격 성공률 | 해석 |
|:---:|------|
| 0.0 ~ 0.1 | 우수 — 취약점이 거의 없음 |
| 0.1 ~ 0.3 | 양호 — 적대적 조건에서 일부 공격이 성공 |
| 0.3 ~ 0.6 | 우려 — 상당한 취약점 |
| 0.6 ~ 1.0 | 심각 — 쉽게 악용됨 |

> 주의: 카탈로그 데이터에는 통과 여부(`pass`)와 기준값(0.85)이 함께 들어 있는데, 위 기준과 방향이 반대입니다. 공격 성공률 1.0인 모델이 통과로 표시됩니다. 탭에 통과/실패 표시나 색상이 나온다면 시연 전에 어떤 의미로 표시되는지 확인하세요.
